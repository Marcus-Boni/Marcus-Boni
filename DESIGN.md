# Design

## Source of truth
- Status: Active
- Last refreshed: 2026-11-25
- Primary surfaces: GitHub profile README and its Portuguese translation.
- Evidence: the approved chrome portrait, its extracted glyph grid, `marcusboni.com.br/blog`, and the public repositories (`ISPer`, `OptTime`, `chatbot-template`, `Marcus-Boni-Portfolio`).
- Direction chosen by Marcus: minimalist, standardized monochrome palette (**silver, white, gray, and black**) harmonized directly with the chrome bust GitHub avatar — zero accent hues outside the grayscale/chrome scale. English first, with a Portuguese translation.

## Brand
- Personality: minimalist, modern, systems-minded, verifiable.
- Trust signals: inspectable source permalinks, release discipline, modular architecture, AI-assisted craft grounded in fundamentals, active technical writing on the blog.
- Avoid: orange or colorful accents, badge walls, heavy dense blocks of inline code tags, third-party stat widgets, repeated contribution calendars.

## Visual language
- Strictly monochrome across both themes: obsidian black, graphite, cool neutral grays, brushed silver, and crisp white in dark mode; paper white, pale silver, charcoal, and deep ink in light mode.
- Hero (`assets/hero-terminal-v4*.svg`): minimalist dual-pane chrome terminal pairing `$ whoami`, `Marcus Boni`, `Forward Deployed Engineer`, and a blinking silver blog prompt beside the animated 82×39 liquid-chrome ASCII bust (white-silver raster scan + dual continuous specular reflections).
- Architecture (`assets/systems-blueprint-v2*.svg`): minimalist 4-layer ASCII schematic (`Interfaces` → `Applied AI` → `Systems & Data` → `Cloud & Ship`) with animated silver/white signal packets and synchronized border/LED illumination.
- Reduced motion renders both figures immediately at 100% static clarity.

## Information architecture
- Hero terminal → concise intro + Portfolio/Blog/LinkedIn/Email links → `Selected work` (`01`–`04`, concise 2-sentence engineering summaries) → `Architecture & stack` (animated ASCII blueprint + clean plain-text stack summary) → `Writing` (blog reference) → expandable `More work` → visible `How I build` (including AI-assisted engineering & continuous learning) → closing contact line.
- Keep implementation credits out of the visible README footer, as requested by Marcus.
